# Summa

Summa is a functional, local-first Android personal finance app for one person. It is Catalan-first, euro-only, and designed to keep financial meanings explicit without requiring a hosted account, bank connection, or cloud database.

> [!IMPORTANT]
> Android is the working product. Summa remains a personal project in active development; investment valuation and cross-device synchronization are not implemented, and there is no public production release yet.

## What it tracks

Summa distinguishes concepts that many expense trackers collapse together:

- **Account flow** — what physically entered or left an account.
- **Actual income/expense** — what economically belongs to the app owner.
- **Shared expenses and debt** — economic splits and derived balances between people.
- **Shared accounts** — physical balance, ownership share, contributions/withdrawals, and expense allocation.
- **Budgets and forecasts** — based on canonical actual spending.
- **Savings goals** — reservations of existing money without inventing ledger activity.
- **Trips, categories, tags, recurring activity, and analysis** — context over the same financial truth.

## Current Android capability

- personal and shared accounts;
- expenses, income, transfers, refunds, settlements, contributions, and withdrawals;
- people, splits, shared income allocation, and derived debt;
- recurring templates and due-item confirmation;
- monthly/yearly budgets, trip budgets, and forecasts;
- trips, categories, tags, search, and filters;
- savings goals backed by dedicated accounts or manual allocations;
- dashboard and period analysis;
- System/Light/Dark themes, notifications, backup, and restore.

The UI follows the **Personal Compass** direction: warm, private, precise, and evidence-led. Financial meaning is labelled rather than conveyed by colour alone.

## Architecture

Current production architecture:

```text
Compose UI
    ↓
ViewModel / screen state
    ↓
repository or small domain rule
    ↓
SQLDelight
    ↓
SQLite
```

`shared/` contains the schema, migrations, genuinely canonical finance SQL, focused golden vectors, and design tokens. The current `windows/` project is a .NET validation harness; a Windows product has not started.

There is no server in the current product. Future Windows and synchronization ideas are deliberately separated from current architecture so they do not force speculative abstractions into Android.

## Technology

| Area | Technology |
| --- | --- |
| Android | Kotlin, Jetpack Compose, Material 3, coroutines, StateFlow |
| Persistence | SQLite, SQLDelight |
| Shared finance contract | SQL schema, migrations, canonical queries, JSON golden vectors |
| Contract validation | .NET 8, C#, Microsoft.Data.Sqlite, Dapper, MSTest |
| Automation | Gradle, Python validation scripts, GitHub Actions |

## Financial correctness

- Money is stored as integer euro cents.
- Balances, account flow, actual income/expense, debt, trip actuals, and goal progress are derived from canonical SQL.
- Schema changes use forward migrations.
- Focused procedural finance rules use shared golden vectors where exact parity matters.
- Risky but valid actions warn; structurally invalid ledger states remain errors.
- Normal finance deletion is recoverable soft deletion.

## AI-developed, human-directed

Summa has been developed using OpenAI Codex and Anthropic Claude Code. The maintainer defines product behaviour, approves financial semantics, tests real flows, and decides which generated changes are accepted.

Repository-level agent guidance lives in [`AGENTS.md`](AGENTS.md). Optional specialist configurations are intentionally minimal: a reviewer and a schema steward for changes where they materially reduce risk.

## Build and test

Requirements: JDK 17, Android SDK 35 / Build Tools 35.0.0, and .NET 8 SDK when validating the shared contract.

Android, from `android/`:

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest
```

.NET contract harness, from the repository root:

```powershell
dotnet test .\windows\GestorFinances.Tests\GestorFinances.Tests.csproj
```

## Scope

Summa is intentionally single-owner, euro-only, Catalan-first, and local-first. It currently has no authentication, hosted account, live bank connection, implemented Windows UI, investment-price feed, or cross-device synchronization.

No open-source licence has been selected yet; unless a licence is added, the source should not be assumed to grant reuse or redistribution rights.

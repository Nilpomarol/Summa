Read `docs/product.md` and `docs/design.md` first. The redesign is intentionally open-ended: design the item selected with the user instead of inventing a phase backlog.

Rules:

- Android is mobile-first; Windows uses desktop-appropriate structure and interaction.
- Preserve honest actual-versus-flow meaning, derived balances, warn-not-block behaviour, and unmistakable read-only state.
- Externalize all Catalan copy.
- Explore structure, interaction, copy, and visual style to the depth requested.
- Keep page-specific exploration in the current task. Update `docs/design.md` only for durable cross-product decisions or when the user asks for documentation.
- Do not create per-screen specifications, trackers, or redesign backlogs unless asked.
- Do not write application code.
